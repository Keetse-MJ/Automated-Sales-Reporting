# Automated Sales Reporting

## About the Project

This is a MySQL project focused on automating sales reporting and database operations.

## Tools Used

* MySQL
* SQL

## SQL Concepts Used

* Temporary Tables
* Stored Procedures
* Triggers
* Events
* Aggregate Functions
* GROUP BY

## Dataset

The dataset contains sales information including:

* Sale ID
* Salesperson
* Region
* Product
* Category
* Quantity
* Amount
* Sale Date

## Project Files

* `automated_sales_reporting.sql` - Database, sales table and sample data
* `01_temporary_tables.sql` - Temporary table practice
* `02_stored_procedures.sql` - Stored procedure practice
* `03_triggers.sql` - Trigger practice
* `04_events.sql` - Event practice

## What I Learned

Through this project, I practised using MySQL to automate database tasks, create reusable procedures, track data changes with triggers and schedule automatic reports using events.
